## Authentication

### TC-001 — Verify successful login with valid username and password redirects to Dashboard
**Feature:** User Login · **Priority:** P0 · **Type:** positive · **Severity:** Critical

Confirms a registered user with valid credentials authenticates through the standard login form and lands on the Dashboard. This is the primary gateway to all HR functionality and is the highest-value happy path.

**Precondition:** The OrangeHRM QA login page is reachable at https://opensource-demo.orangehrmlive.com/web/index.php/auth/login. A valid registered account exists with username 'Admin' and password 'admin123'. No active session exists in the browser.

**Steps:**

1. Navigate to https://opensource-demo.orangehrmlive.com/web/index.php/auth/login → Expected: Login page loads showing the OrangeHRM logo/branding, Username field, Password field, Login button, and the 'Forgot your password?' link
2. Enter 'Admin' into the field labelled 'Username' → Expected: Username field shows 'Admin'; no validation message is displayed
3. Enter 'admin123' into the field labelled 'Password' → Expected: Password field shows masked characters; no validation message is displayed
4. Click the 'Login' button → Expected: Within 3 seconds the user is redirected to the Dashboard (URL contains /dashboard/index) and the top-bar user menu is displayed

**Expected Result:** The user is authenticated, an authenticated session is created, and the Dashboard is displayed.

**Tags:** smoke, regression, auth
